# Research notes

One file per specialist. Every source listed was actually fetched by the researcher; anything not fetched is marked
"to verify". Each file ends with a distilled checklist that the skill is built from.

`research-specialist.md` is the research specialist's own knowledge base and follows this exact convention like
every other file here -- it is not a special case. Any specialist's research file can be refreshed by consulting
the research specialist (`skills/research/SKILL.md`) instead of doing an ad hoc, unverified lookup; see its
`handback-reference.md` for how it extends an existing research file without overwriting prior provenance.
