## 1. How the web specialist uses this file
- Use these as **reference and source libraries during the study step** (see the reference-site study file), not as a place to copy a finished design from. A section that is lifted whole from a gallery is the "looks AI / same as before" failure the operator keeps reporting.
- Before an order says "use asset X from site Y", check section 3 for the licence. If the project is client work, ads or a resold template, a paid licence or a free tool export is required, and the order says which.
- Name the reference in the order ("hero pill loader after the Composer Loader pattern, our own colours"), so the builder knows what was borrowed and what was invented.

## 2. Choosing a resource by need

## 4. inspora.design
- A curated archive of recent design work; it links out and does not host the work. Top nav: Design, Websites, Logos, Contact, About, Sponsor. Home filters: All, Web, Branding, Product, Motion, Illustration, 3D, Print.
- The /websites index has three filter groups with counts (as read): **Theme** (3D 22, Animated 55, Dark 18, Gradient 7, Grid 13, Illustration 14, Interactive 30, Minimal 24, Typography 26, Video 14 and others), **Category** (Design 18, Development 15, AI 14, Software 14, Technology 11, Agency 9 and others) and **Color** (Black 49, White 48, Blue 24, Green 23, Gray 22 and others). Roughly 60 entries were visible; the total is **(unverified)**.
- Copy the pattern, our judgment: filter by theme, category and colour with counts, and a grid of logo plus one-line description cards. Useful as the structure of our own reference library.
- Technique titles seen on the home feed (title only, posts not opened): carousel turns into top navigation, one-tap menu bypass, rainbow glow button, audio-reactive voice visualizer, dust particle deletion, shader logo colouring.
- Sponsor slots are priced and marked "Sponsor", so a featured entry is not automatically an editorial pick.

## 5. horizonx.so
- Premium UI and code library: UI kits, components, Figma files, textures, shaders, mockups, icons, sounds, 3D models, cursors, game assets. It claims 1000+ products **(unverified, self-reported)** and has an MCP server and a "Copy Prompt" feature that gives an AI-ready prompt per component.
- Plans as read: Starter $24.99 a month (5 premium downloads a month), Pro $39.99 (12), Max $99.99 (25, 3 teammate invites). Yearly prices were not read.
- Named effects worth studying (names as shown): Riso Glow, Dither Text, ASCII, Retro Matrix textures; Liquid Glass, Glass Effort Slider, Tunnel Fold Slider, Plasma Orb, Assistant Pill; hero patterns such as a water hero, an AI particle hero and a tunnel hero.
- Terms are in /terms (last updated 2026-10-26); the key limits are in section 3 above.

## 6. backgrounds.supply
- One-time $49 for 1,983 backgrounds in 53 collections, every background 16:9, with monthly drops; plus free browser tools **(counts as read)**. Free page: 200+ free aesthetic backgrounds.
- Tools worth knowing: Gradient Lab (animated gradient styles, a draw mode, export to PNG or MP4 or WebM), Halftone Gradient Generator, Grain Texture Generator, Gradient Map (duotone), Image to Gradient, Animated Background Generator.
- Our judgment: the free generators are a licence-safe source for grain and gradient backgrounds where we would otherwise ship an AI-looking stock image; the 16:9 only format means phone crops must be checked at 390 px.
- The web app that holds the actual downloads is JavaScript-driven and was not read.

## 7. boardui.com
- React design system for dashboards and agent interfaces: 104 components (19 charts), 10 Pro templates, 400+ tokens, built on React 19.2, Tailwind CSS 4, React Aria and TanStack Table, with Recharts for charts. Installed with `npx boardui@latest add <component>`, which copies the source into the project.
- **Composer Loader**, a concrete effect to copy the idea of (not the code): an iridescent light band travelling the pill's rim at constant speed, led by a crisp refraction line with a soft bloom behind it; one `waiting` boolean drives it; tunable colours (four stops), arc, bloom, bloom strength, speed and radius; motion stops under `prefers-reduced-motion`.
- Chart set to borrow vocabulary from: activity rings, funnel, heatmap, radar comparison with outline-only series, Sankey with hover isolation, half-gauge speedometer, stage bars.
- Dashboard layout as shown: stat cards, a sidebar with search and badges, an activity heatmap by month, an alerts panel, a data table with filter, sort and pagination.
- The page shows two lifetime prices (struck €249 to €199 and a "€49 launch discount" label) that do not agree **(unverified)**.

## 8. posts.design
- A hand-picked gallery of real social posts from brands and designers (launches, carousels, OG images, X headers); each entry links to the original post. The public preview shows 48 of 2,375 references.
- Each entry carries kind, media, posting account, represented brand, categories, subjects, dates and capture size. Capture sizes seen: 1280 by 720, 1080 by 1080, 1024 by 1280 and 960 by 1280, and 2400 by 3000 tile sets.
- Category labels: Launch, Feature, Hiring, Content, Branding, Award, Event, Poster, Integration, Milestone, Teaser, MCP, Update. The media is video or image and was not visible as text, so no motion values are available here.

## 9. 60fps.design
- UI animations from iOS apps, broken down frame by frame. Home counts as read: 2,150 shots, 499 apps, 96 app sites, 83 motion, 32 snippets, 67 storyboards. The "151.8K+ followers" figure is a site claim **(unverified)**.
- Filter taxonomy, usable as the vocabulary for a motion order: **Gestures** (drag, flick, flip, hold, long press, pan, pinch, pull, scroll, scrub, slide, swipe, tap, typing), **Patterns** (card stack, carousel, empty state, onboarding, pricing and about 35 more), **Effects** (spring physics, stagger, morph, parallax, shimmer and about 35 more), **Elements** (bottom sheet, liquid glass, segmented control and more).
- Worked example read in full: the Airbnb gift-card intro. A stacked deck of illustrated cards splits and fans outward on entry; the centre card stays upright while the left and right cards translate outward and rotate into a spread with gentle spring physics.
- No durations or easing curves are given in the text, so a motion order that cites a shot still has to state its own numbers and check them.

## 10. footer.design
- A curated footer gallery, a passion project run by three people (credits on /info). Filter by style: Typographic, Small Type, Illustrative, Grid, Flat, Animated, Cards, Bright, Dark, Large Type, Bold. Each card shows a thumbnail, the site name, an Editor's Choice badge where it applies and a Visit button, and links to a detail page.
- Only the style names and the card anatomy were readable; thumbnails and detail pages were not opened, so no footer layout is described here.

## 11. bencho.dev
- A library of about 150 interactive React blocks and micro-interactions **(approximate count from the list)**, each tagged by interaction: hover, press, drag, loading, type, swipe, select, slide. Also sounds, finds and a bench. Free tier is a selection; Pro is €99 a year or a pay-once tier, with full source and MCP access.
- Thinking Orb as read: an AI "thinking" indicator on a canvas, a sphere of dots turning in 3D with nearer dots larger and darker, hover wakes it, a `style` prop switches Spinning or Weaving (dots on breathing rings), and a shimmering "Thinking" label.
- Block names seen, behaviour not verified: FAQ accordion, toast stack, pull to refresh, collapsing sidebar, command bar, dynamic island, radial menu, slide to confirm, magnifying dock, elastic slider, liquid tooltip.

## 12. What was not read
- posts.design: /terms and everything after the first 40k characters of the home page except a model summary; the browser-only search and brands pages.
- 60fps.design: terms, glossary, why page, and all but the first 30 of 2,150 shots.
- inspora.design: /terms, /logos, individual posts; the JavaScript-loaded feed beyond its first batch.
- footer.design: /browse, /submit and every detail page.
- horizonx.so: explore, tools, textures, drops licence, MCP and yearly pricing; the "1000+" and review numbers are self-reported.
- backgrounds.supply: the web app, collection pages, the policy pages, and the tail of the freebies page.
- boardui.com: the Pro licence text, installation and MCP pages; live previews.
- bencho.dev: the licence text, docs, MCP, sounds, finds and bench pages; all live demos.
